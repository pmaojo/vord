# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The `yunq` security team takes security vulnerabilities seriously.

If you discover a security issue or vulnerability in `yunq`, please do **NOT** open a public GitHub issue. Instead, report it privately to our security team:

* **Email**: `security@yunq.dev`
* **Response SLA**: Within 24 hours.
* **Patch Release SLA**: Within 72 hours for Critical/High vulnerabilities.

Please include:
* Description of the vulnerability.
* Steps or proof-of-concept to reproduce.
* Affected components or crates.

We appreciate your effort in practicing responsible disclosure!
